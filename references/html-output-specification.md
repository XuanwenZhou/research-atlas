# 原型分析与通用输出

## 实际原型

项目没有请求中简写的 reference 路径，使用用户明确提供的增强版附件。完整 JSON 程序解析，CSS/DOM及约3.4万字符脚本逐段检查：493方法、21分类、464全域边、5综述；research 有2组9路线、250成员、341专题边和250日期审计。methods 混合论文/方法，groups 泳道，edges 方法引用，surveys 溯源，research 专题。

原时间分段2020–2026、SLAM固定组、九路线及近期年份为领域硬编码。通用模板去掉这些常量，原型记录只存在回归数据；旧待核关系不提升状态。

## 保留视觉与交互

温润纸感底色、高对比白卡片与轻微层次阴影、矿物青品牌强调色（与 Research Atlas 标志统一）、清晰学术排版字阶、可滚动树形分类侧栏（自动将二级子类归并缩进到所属一级类下方）、三/二/单列卡片、24条分页、右详情、明暗主题、响应式及打印。两核心页签：合集和演进图。

合集：一二级分类和辅助归属筛选，名称/论文/作者/机制搜索、年份、排序、代表标记、分页/空状态/重置、详情弹窗、图定位。当前筛选结果支持 JSON、文献 CSV 和 BibTeX 导出，文献按关联论文 ID 去重，保留已有元数据，不补造会刊或日期。CSV 处理公式文本，BibTeX 转义特殊字符并保护标题大小写（`{{...}}`），与 Python 导出器保持一致。详情按学术阅读方式展示作者、已有日期和发表记录、问题（与机制完全重复时自动折叠避免双倍展示）、机制、贡献、价值、场景、局限及模块。缺失字段不逐项显示占位；日期审计记录整理为可读信息和来源链接，不展示原始 JSON。

演进：横轴动态年份，未知日期单独分箱，年内按日期排序；分箱不是连续精确日期刻度。纵轴按主分类（自动按父子有序聚拢）分泳道，带低饱和度分组色条，辅助归属用于筛选，避免重复节点。首次打开和重置均展示全部收录方法，不自动生成精选主线。支持方向/关系筛选、搜索定位、节点/边详情、前驱后继/借鉴/theme、高亮邻居并将高亮连线自动置顶、跨泳道多轨错峰路由、缩放/Ctrl滚轮/拖动/适宽/全屏/SVG。direct 钴蓝实箭头，extension 矿物青虚箭头，borrow 赭棕点划箭头，theme 冷灰点线无箭头。连线详情保留类型徽标、事实/推断及核验状态、关系说明，并通过规范化 URL/arXiv/DOI 匹配原论文标题，同时展示已记录的原文位置（locator）、短摘录与核验日期。

参考来源按实际溯源关联的综述论文去重，显示作者、综述标题及链接；不把全部项目综述自动挂到每个方法。原论文保留独立入口，连线依据保留实际支持文献及原文定位。导入批次、内部 ID、阅读层级代码和重复审计提示留在 JSON 与核验报告，不堆入阅读界面。来源记录和核验状态不因展示简化而删除或升级。

## 通用数据驱动

canonical JSON 唯一权威；build 仅内嵌一份紧凑 `{"canonical": ...}`，前端启动时按需还原展示视图并兼容历史预展开格式，避免 HTML 中双份存储导致体积翻倍。内嵌 application/json，无 fetch/CDN；JSON 中小于号转义防止闭合script，文本 HTML 转义并优雅渲染常见 LaTeX 上下标，链接仅http/https。

领域名称、分类、统计数量、年份范围和核验状态以当前项目数据为准。固定文案只解释阅读方式，不默认宣称日期已逐篇核验或文献收录穷尽；详情提供日期来源和关系依据，完整核验状态见数据及报告。

专题视图由 research_tracks 配置，支持多组路线、跨归属、时间范围和日期CSV；无配置时隐藏入口。专题成员和关系引用现有数据，可与原合集同时浏览。兼容器读取外部 --profile，将旧专题范围转为配置，通用模板不含领域名或固定年份。

SVG 内嵌样式和主题色，去交互命中层和临时高亮。当前合集导出有效 canonical 子集，能重建。

搜索唯一节点时自动显示它及直接关联节点和连线，避免将前驱、后续过滤成孤点；继续搜索时先清除上一节点的邻居范围，清空搜索恢复当前筛选范围，重置恢复全部方法。

图谱的起止年份依据当前数据生成。年份范围与技术方向、关系类型组合筛选；限定年份时，缺日期节点不被猜测归入某年，范围外节点不进入路径。起止倒置时同步调整另一端，使范围有效。

选中节点后可主动切换直接关联、前驱技术路径、后续技术路径或上下游技术路径。多跳遍历只沿现有 direct/extension/borrow 边，遵守方向、关系筛选和年份范围；theme 不构成继承路径。上下游分别遍历后取并集，不经子节点绕入其他父节点，循环关系不得造成重复或死循环。路径中所有节点和边保持高亮；关系的事实/推断和核验状态仍以原数据为准，路径追踪不升级证据。

模板不自动提取PDF、检索、推断机制；数千节点需进一步性能评估，不能承诺无限规模。全屏失败有提示，无JS有提示。
