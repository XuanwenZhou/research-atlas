# 沿路线检索

采用实际当前日或用户截止日。用户未指定近期范围时，优先覆盖当前年及此前两个自然年，同时沿引用回查早期基础和桥接论文。

1. **准备覆盖表。** 列出技术分支和各年份，记录已覆盖和偏薄的组合。每个分支使用问题词、机制、代表论文、领域别名等组合。按任务选择有关会刊与预印本渠道。
2. **独立查目录、引用和主题。** 从原始综述的参考文献出发，扫描目标会议/期刊的官方目录，追踪不同分支代表论文的前向引用，再用主题搜索回收新路线、少引工作、交叉工作和负面结果。按年分段，遇到接口返回上限时分页或拆分；单次最新排序的结果只覆盖该查询窗口。某渠道受限时换正式可读版、作者稿或开放索引并记录。
3. **从候选到纳入。** 标识及题名去重，再读摘要或相关正文，注明实际阅读层级。核对预印本 v1、录用和正式出版——从会刊目录批量纳入仅有年份的论文时，建议通过 arXiv/Crossref/OpenAlex 补查 `doi`、`arxiv_id` 与首发日期，避免大批论文全部堆在纯年份桶里。给新增论文提炼简洁方法名（完整原标题留 `paper.title`）、独立研究问题与机制、纳入理由、existing/new_branch/bridge 及有据关联方法。引用存在不等于技术继承；已找到相关工作但未核关系时保留节点，同时避免整批新增论文几乎全部孤立而未做关系回查。
4. **按缺口追加。** 首批方法可用于验证字段和 HTML。完整整理或明确要求大范围补充时，继续检查近年分支是否遗漏、结果是否停在接口首屏、不同会刊是否漏搜。对缺口发起新查询并回收候选。根据新批次的重复程度、相关工作产出和仍未覆盖的范围说明结束依据，允许分批交付与继续更新。无关论文、仓促推断的边和重复发表记录不计入覆盖。

日志最少 date/channel/query/scope/hits/included/excluded/failures。可将“方向、年份、会刊、查询批次、返回记录、去重候选、已审、已纳入、待审、访问限制”作为覆盖表列项。区分返回记录、题名初筛和实际阅读计数，保留候选及主要排除理由。说明未覆盖目录、年份、语言和数据库，有限检索不得宣称全领域穷尽。综述的刊物等级和被引量可用于引种，近年原始工作按范围和证据纳入。

无网络则继续本地资料，明确缺失的新文献搜索/URL复核，不伪造访问日志和最新结论。脚本负责转换，Codex 负责实际阅读、分类和证据判断。
