# 验收与交付

检查缺失/重复ID及稳定性、DOI/arXiv/标题候选、强标识冲突、有效论文/分类/边/专题引用、分类无环且一二级有序连续、主分类完整、代表方法存在。检查四类边、同对重复边、事实/推断（禁止仅凭题名/元数据标 fact）、置信度、已核边原始全文证据及位置、日期精度和分列、problem 与 mechanism 是否误复制、URL协议和实际访问状态、动态统计。逆时边与孤立节点高占比须人工回查。

运行 validate_data、deduplicate_papers、build_html、export_bibliography。结构错误必须修；证据待核草案允许构建，但交付 unresolved。--strict 供完成核验后的验收，不能把导入旧数据强行升级。

交付前检查近期各方向是否实际检索、是否覆盖相关会刊及引用链、是否有截断的查询或尚未筛查的候选。发现可补的明显空白就继续检索，再更新按方向和年份的新增统计。区分候选、纳入和全文核验。首个 HTML 构建成功只证明展示可用。

真实浏览器 file:// 离线检查双页签、24条分页、搜索/空结果/重置、年份/方向/代表/排序、弹窗作者和来源、图定位、首次打开及重置后均展示全部方法、分类/四类关系、节点/边详情、邻居高亮、缩放/拖动/适宽/全屏、JSON/CSV/SVG下载、明暗/键盘/窄屏。下载后解析并核对计数，不只看按钮。

详情中的综述来源与实际溯源对应且不重复；缺失元数据不堆放占位，审计信息不以原始 JSON 或导入代码展示。确认可读日期与记录一致、推断关系在连线详情中说明、导出数据仍保留原证据和状态。

除核对边总数，还逐项检查用户指出的节点是否实际有入边或出边；区分原始关系缺项、迁移丢失和筛选隐藏。搜索唯一方法时应保留直接关联上下文，核对新增连线在图中、节点详情及导出文件中均可见。孤立节点只补有来源的关系，不以补齐数量为目标。

补测年份范围的边界、倒置区间、未知日期与重置；多跳路径的方向、主题边排除、上下游并集、循环终止和高亮。CSV/BibTeX 按当前筛选结果导出，检查一文多法去重、CSV公式与引号换行、BibTeX特殊字符，以及与命令行导出的字段一致性。仓库动图和截图须来自真实界面操作，说明筛选条件，避免把局部演示写成默认主线或将未实测功能写为已完成。

小示例测一文多法、辅助分类、跨年/未知日期、四类边、缺元数据、无专题；原始回归核493节点/464全域边、专题成员/边、日期审计、作者和引用。补测坏ID/引用、危险URL、HTML注入和合并重定向。修复后跑受影响检查及必要回归，不为固定轮数空跑。

必交：HTML、project-data.json、groups.json、edges.json、bibliography.csv/bib、verification-report.md、validation.json、unresolved.json。保留检索日志/确认记录/版本。分别报告单元测试、浏览器交互和学术核验；未执行项不能写通过。
